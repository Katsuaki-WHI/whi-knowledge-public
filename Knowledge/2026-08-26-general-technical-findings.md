# 一般技術Tips（JS の replace / 表の横スクロール）（2026-08-26）

## 1. JavaScript の `String.replace` は最初の1個しか置換しない

- `str.replace("{x}", v)` は**最初にマッチした1個だけ**を置換する。同じプレースホルダーが複数あると2個目以降はそのまま残る。
- **全部置換したいときは `replaceAll`**（または `replace(/{x}/g, v)`）を使う。
- **実例**：メール本文で `{currentCount}` が3回中2回そのまま表示された（1個目だけ置換されていた）。
- i18n のプレースホルダー置換で特に注意＝同じ変数が本文中に複数回出るテンプレは `replaceAll`。

## 2. 表がコンテナより広いと常に横スクロールする

- テーブルの実幅がラッパーの幅を超えると、**常に横スクロールが出る**（中身が収まらない）。
- **実例**：826px の表を 764px の器に入れていた → 常時横スクロール。
- **対処**：狭い幅では「表」でなく「カード」に切り替える。切替のブレークポイントを見直す（実例では **768px → 1024px に変更**して、タブレット幅でもカード表示にして解消）。
- 教訓：レスポンシブの表は「器の幅 vs 表の実幅」を実測し、収まらない幅ではレイアウトそのものを変える（列を削る／カード化する）。狭い幅の実機で目視する（[[build-pass-not-runtime-ok]]）。
