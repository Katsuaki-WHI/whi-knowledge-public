# 「差が無い」を `=== 0` で見ない／段階は丸めたあとの数から決める

★どちらも **SQW の価値観15問の「一致度」（スタイル×欲求の相関）を作ったときに、
自分で書いた検査が自分の実装を捕まえた**2件。相関・偏差・ばらつきを扱うところで必ず再発する。

## 1. 「差が無い」を `=== 0` で見ると取りこぼす

相関（ピアソン）は、どちらかの並びに**差が無い**と答えが出ない（0で割る）。
だから「差が無ければ測れない（null）」と倒す必要がある。
このとき **`分散 === 0`** と書くと**取りこぼす**。

```
3.2 を6つ足して6で割る → 3.1999999999999997
3.2 − 平均 = 4.44e-16 ≠ 0
→ 分散は 1.2e-30 で「0ではない」
→ 測れないはずの人に「一致度 0 → 中」が出る
```

★**0 と比べるのでなく、小さな幅（1e-12 など）と比べる。**

★**怖いのは、出てくる数がもっともらしいこと**＝`0`（中）は
「差が無い」ではなく「関係が無い」と読めてしまう。
**測れないことと、測ったら関係が無かったことは別**なので、
**測れないときは null にしてレポートに出さない**（出すと、無いものを読ませる）。

★**見つけ方**＝検査に「**測れないはずの入力**」を必ず1本入れる
（全部同じ点数の人・力が全部0の人）。
通る側だけ試すと、この取りこぼしは**絶対に出ない**。

## 2. 段階（高・中・低）は「丸めたあとの数」から決める

数を画面に出すときは丸める（0.4999… → 0.5）。
段階を**丸める前の数**から決めると、**画面の数と段階が食い違う**。

```
本当の相関 0.4999…  →（線は0.5以上が「高」）→ 段階は「中」
画面に出す数 round(0.4999…) = 0.5
→ 読む人には「0.5 なのに中？」としか見えない
```

★**丸めてから段階を決める。**（画面に出す数と判定の数を同じものにする）
★一般則＝**人に見せる数と、判定に使う数を別々に作らない**。
　同じ型＝[[placeholder-values-break-when-premise-changes]]（表示と判定が別の値を見る）。

## 3. おまけ：理論の原語を「禁止語の印」にできないことがある

「理論の出典名・原語を材料に出さない」を機械で数えようとして、
原語（`Certainty`／`Variety`／`Significance`）を印にしたら**全部当たった**。
調べると当たった先は：

- `Variety` ＝ 正典の60語そのもの（変化 priority 6「多様さ」）
- `Certainty` ＝ 正典の60語そのもの（安定 priority 10「確実さ」）
- `Significance` ＝ **自分が書いた注意書き**（「原語（Certainty / Significance 等）は入れません」）

★**原語がふつうの語と同じ綴りのときは、印に使えない**（使うと正しい語を違反にする）。
→ 印にするのは「**ふつうの語としては出てこない、理論だと分かる言い回し**」だけ
（`Love & Connection`／`Six Human Needs`／`DiSC`／`Gallup` など）。
★**数えるのはデータだけ。コメントは外す**（[[mistakes]] 2026-10-04・当たりが広すぎる型の再発）。
